# MW 组件库设计师使用手册

## 1. 使用总原则

设计师只从组件库拖拽最外层组件实例，不展开并复制内部的“默认、悬停、按下”等变体定义。

组件使用流程：

1. 从 `MW/按钮`、`MW/下拉框`、`MW/输入框`、`MW/表格` 或 `MW/布局` 中拖出组件。
2. 选中最外层实例。
3. 在右侧“组件属性”中设置状态、文案、图标资源等属性。
4. 需要更换图标时，使用“图标资源”的实例切换，不要删除内部图标容器后自行拼接。
5. 需要多个按钮时，复制外层实例；不要复制组件集内部的状态变体。

## 2. 设计师可以修改什么

可以修改：

- 组件属性面板中已经暴露的文本、布尔开关、状态和实例资源。
- 图标资源实例切换为组件库中已有的完整图标组件。
- 布局容器插槽中允许放入的受控子组件。
- 页面中的实例数量、排列顺序和业务文案。

不能直接修改：

- MW 框架样式键，例如 `MainButtonStyle`。
- `IOEnable`、`PageName`、`s:Action` 等工程协议。
- 组件内部固定结构、状态变体的层级和资源容器。
- 用普通图层替换框架控件的核心子结构。

## 3. 图标按钮

### 什么时候用

当操作需要图标、文字、快捷键提示或状态反馈时，使用图标按钮。

### 怎么选

| 需求 | 选择 |
|---|---|
| 图标在上、文字在下 | 主图标布局 |
| 图标和文字左右排列 | 右侧横向布局 |
| 图标和文字上下排列的紧凑形式 | 右侧上下布局 |
| 底部操作按钮 | 底部标准布局/底部小布局 |
| 灰色紧凑操作 | 灰色紧凑布局 |
| 只需要图标 | 纯图标布局 |

### 怎么换图标

选中最外层按钮实例。图标按钮统一使用单一组件 `MW/图标/图标资源` 作为“图标资源”插槽。设计师通过最外层“图标资源”属性替换完整图标，并可直接调整图标实例的宽度、高度和位置。按钮宽度可以随文本适应或填充父容器；不要直接修改内部路径，也不要把复杂图标拆成普通图层。当前按钮变体的槽位实例替换仍需在 MasterGo 中逐项绑定完成后，才可正式发布团队库。

### 状态怎么设置

在最外层实例的“状态”属性中选择：默认、悬停、按下、选中或禁用。图层树中看到的这些文字是状态变体值，不是需要设计师重新命名的业务组件。

## 4. 组合页面时的边界

按钮网格、按钮组、表格和列表属于容器组件。容器内部允许放置哪些子组件，以组件的“插槽/允许子项”说明为准。不能因为画布空间足够就任意增加未登记的结构；如果需要新的子控件类型，应先补充组件库和映射文档。

## 5. 状态按钮、切换按钮和单选按钮

### 状态按钮

用于展示设备或流程的 ON/OFF 状态，不用于表达普通鼠标悬停状态。设计师只选择“状态”和“按钮文本”；颜色和指示灯由组件状态决定。

### 切换按钮

用于开启或关闭一个可以保持的功能，例如启用自动模式、打开辅助功能或启用联锁。选择“未选中”“选中”或“禁用”，不要用普通图标按钮模拟开关。

### 单选按钮

用于一组选项中只能选择一个的场景。多个单选按钮应放在同一个明确的选项组容器中；单个单选按钮不能代替整组选项。

这三类组件分别对应 MW 的 `StatusButton`、`IOToggleButton` 和 `IORadioButton`，不要互相替代。

## 6. 按钮组和主按钮网格

### 按钮组

用于把多个相关按钮组合成一个横向或纵向的选择/操作区域。先选择“方向”，再把已登记的图标按钮、切换按钮或单选按钮放入“按钮项插槽”。不要把普通文本图层、矩形或未登记组件直接放进按钮组。

### 主按钮网格

用于工控页面中的主功能按钮排列，典型场景是 `F1`～`F14` 的操作网格。网格中的子项应使用主图标布局的图标按钮；业务文案、快捷键、图标和工程动作属于每个按钮实例自身的属性或 AI 工程映射。

按钮组和主按钮网格是容器，不是一个“大按钮”。设计师可以增加或减少受控按钮项，但不能改变容器内部的框架结构。

## 7. 交付前检查

- 是否使用了正式组件库中的最外层实例。
- 是否通过属性面板修改，而不是直接破坏内部结构。
- 图标是否仍然是完整的图标组件实例。
- 是否使用了正确的布局和状态。
- 是否把页面跳转、动作和联锁误填成了设计属性。
